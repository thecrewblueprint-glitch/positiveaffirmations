## Archive boundary

Exact historical Markdown revisions for the prior README, deployment guide, and Google Calendar architecture plan are retained in the Roadmap archive/memory system with Git-source verification.

Git history remains the exact evidence for removed source/configuration artifacts and rejected branches. Do not rewrite repository history merely to make the project look cleaner.

`files.zip` is deliberately retained for now. It is the original seed archive and the archive-control plane currently reports `missing_package`. Do not delete it until an immutable cold-archive package is registered and a restore/retrieval test passes.

## Reactivation rule

Nothing in memory is deployment authority. Before reactivation, read current source, this file, the current deployment boundary, and the Roadmap memory records; then revalidate dependencies, external providers, OAuth/CORS, secrets, persistence, and scheduler behavior from current documentation and current service state.
